# 🚀 Create Forge App
A project scaffolding tool for creating ForgeCoders applications.

## ✨ Features

- Generate new projects
- Multiple project templates
- Simple command-line interface
- Easy to extend

## 📦 Planned Templates

- Python
- HTML/CSS/JavaScript
- Node.js
- React

## 🚀 Getting Started

### Installation
```bash
git clone https://github.com/ForgeCoders/create-forge-app.git
cd create-forge-app
```

### Usage
```bash
python src/main.py
```

### Troubleshooting
- `python: command not found` — install Python 3.8+ or try `python3 src/main.py`.
- `No such file or directory` — run the command from the repository root.
