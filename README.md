# 🚀 Create Forge App
A project scaffolding tool for creating ForgeCoders applications.

## ✨ Features

- Generate new projects
- Multiple project templates
- Simple command-line interface
- Easy to extend

## 📦 Planned Templates

- Python
- HTML/CSS/JavaScript
- Node.js
- React

## 🚀 Getting Started
```bash
python src/main.py
```
